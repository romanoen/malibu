# Dokumente

Die Dokumente sind aktuell als HTML-Dateien vorhanden:

1. **datenschutz.html** - Datenschutzerklärung (Demo-Version)
2. **leitfaden.html** - Leitfaden zum sicheren Umgang mit Leihmaterial (Demo-Version)

## PDFs erstellen:

Falls du echte PDFs verwenden möchtest:

1. Öffne die HTML-Dateien im Browser
2. Drucke sie als PDF (Cmd+P / Strg+P → Als PDF speichern)
3. Benenne sie um zu:
   - `datenschutz.pdf`
   - `leitfaden.pdf`
4. Lege sie in `/public/` ab
5. Ändere die Links in `index.html` von `.html` zu `.pdf`

Die Links öffnen sich automatisch in einem neuen Tab, wenn der Nutzer darauf klickt.
