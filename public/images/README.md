# Hintergrundbild

Um dein eigenes fotorealistisches Bild des Bodensees zu verwenden:

1. Lege dein Bild hier in diesem Ordner ab (z.B. `background.jpg` oder `background.png`)
2. Öffne `public/styles.css`
3. Suche nach den `url()` Angaben im `body` und `header::before` Styles
4. Ändere die URLs zu: `url('/images/background.jpg')` (oder deinen Dateinamen)

**Empfohlene Bildgröße:** Mindestens 1920x1080px für beste Qualität
**Formate:** JPG, PNG oder WebP
